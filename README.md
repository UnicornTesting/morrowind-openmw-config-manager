## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Settings Editor** | Visual editor for all OpenMW engine configuration options |
| **Data Paths** | Manage multiple Morrowind data directory paths and load order |
| **Profile System** | Save named OpenMW configurations for different mod setups |
| **Config Export** | Export your configuration as a ready-to-use openmw.cfg file |
